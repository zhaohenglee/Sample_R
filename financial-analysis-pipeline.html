Workflow plan · v2 · designed and reviewed on Fable 5.1

Company Financial Analysis Pipeline

Seven stages from filings to a reviewed report. Bulk reading goes to Haiku 4.5, structuring to Sonnet 5 at low effort, judgment to Sonnet 5 at high effort, and one final audit to Fable 5.1. Arithmetic never runs through a model.

Estimated cost $1.40 per company, $2.60 with the Fable review gate Baseline $2.90 on Sonnet 5 throughout Pricing basis Anthropic API rates, June 2026

What changed from v1

Three corrections, stated plainly
  • v1 assigned work to Sonnet 3.5, which is not in the current lineup. The current tiers are Haiku 4.5 ($1 / $5 per MTok in / out), Sonnet 5 ($2 / $10) and Fable 5.1 ($10 / $50). v1's prices were wrong on every row.
  • v1 sent ratio calculation to a model. Ratios are arithmetic on a normalized ledger; a script does it for free and never hallucinates a margin. The model writes the script once.
  • v1 invented generic skills. This plan maps each stage to the skills actually installed in this Claude Code workspace, plus the two tools it needs.

Routing lanes

Four lanes, chosen by the kind of work, not the size of the document. Each stage below names its lane.

Haiku 4.5 Listing lane Read every page, extract every line item, format every export. High volume, no judgment. $1 in · $5 out · 200K context, so chunk filings by statement
Sonnet 5 · low effort Structuring lane Map extracted items to a standard chart of accounts, reconcile, write the workbook. $2 in · $10 out · 1M context holds a full filing set
Sonnet 5 · xhigh effort Execution lane Interpret trends, flag anomalies, benchmark peers, build scenarios, write the narrative. Same rate; effort raises thinking tokens, not price per token
Fable 5.1 Review gate Audit the final deliverable against source pages and challenge each conclusion. Runs once. $10 in · $50 out · the largest single line, so never in the loop

Standing rules

  1. A model reads and interprets; a script calculates. If a number is not in metrics.xlsx, it does not appear in the report.
  2. Stages 1 and 2 have no deadline, so they run through the Batch API at half price.
  3. The ledger, the chart of accounts and the peer set sit first in every prompt and carry a cache breakpoint. Per company questions come after it.
  4. Rework loops go back one stage only. A review finding about a number returns to Stage 2; a finding about an argument returns to Stage 4.
  5. Fable 5.1 runs once per deliverable. If a second audit is needed, Opus 5 at $5 / $25 does it.

Savings levers, in the order they pay

  1. Batch API on Stages 1 and 2: half price, no quality change. Worth $0.50 per company.
  2. Prompt caching of the ledger and peer set across Stage 4 and 5 calls: cache reads cost a tenth of list price. Not counted above, so the true figure is lower.
  3. Effort level before model tier: Sonnet 5 at low effort beats switching Stage 2 to Haiku, because Haiku's 200K window forces chunking and re-assembly.
  4. Model tier last. Haiku only where the task is reading and formatting; Fable only where a wrong number costs more than $1.20.

Review checklist for Stage 6

What Fable 5.1 is asked to do, and only this.

  • Pick ten numbers from the report at random and trace each to a filing page. Report every mismatch.
  • For each of the top three conclusions, write the strongest case against it using only the same metrics.
  • List any metric the report leans on that a peer analyst would define differently, and say which definition was used.
  • Name the single assumption in the scenarios that, if wrong, flips the recommendation.
  • Return open judgment calls to the human with the evidence on both sides. Do not rewrite the report.
Rates: Haiku 4.5 $1 / $5, Sonnet 5 $2 / $10, Opus 5 $5 / $25, Fable 5.1 $10 / $50 per million tokens in / out, Anthropic API, June 2026. Batch API halves list price. Token counts are planning assumptions until replaced by measured usage.
